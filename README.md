# Amazing Flowers Miami

Reference-refined responsive storefront concept for Amazing Flowers Miami.

## Visual direction
The implementation combines the supplied references without copying their placeholder business facts:
- local-florist contact and directions utility
- modern flower-commerce browsing and mobile card rhythm
- editorial floral-studio typography, spacing and photography

## Highlights
- real flower/florist photography throughout
- no fabricated reviews, ratings, store hours, delivery cutoffs or exact prices
- direct links to the official Amazing Flowers Miami storefront for current commerce data
- responsive desktop/mobile navigation
- 4-up desktop / 2-up mobile collection cards
- local call, address and directions actions
- weddings/events and studio-story sections
- decorative Three.js petal layer as progressive enhancement
- reduced-motion and keyboard accessibility support

## Local preview
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.

## Deployment
The repository includes a GitHub Pages workflow that deploys the repository root on pushes to `main`.
